# Changelog

All notable changes to the Trueform Python SDK are documented here.

## [0.1.0] - 2026-08-13

- Added the `Trueform` client and `validations.create` resource interface.
- Added frozen, typed validation result dataclasses.
- Added configurable retries, timeouts, and dedicated exceptions.
- Added validation of successful API response shapes.
